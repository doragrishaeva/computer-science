## 🧩 Algorithmic Patterns

| 🧩 **Паттерн**               | 📌 **Где используется**        | 💼 **Примеры задач на интервью**                                 |
| ---------------------------- | ------------------------------ | ---------------------------------------------------------------- |
| **Two Pointers**             | Работа с массивами и строками  | Move Zeroes, 3Sum, Container With Most Water                     |
| **Sliding Window**           | Поиск подстрок, подмассивов    | Longest Substring Without Repeating Characters, Max Sum Subarray |
| **Divide and Conquer**       | Сортировки, бинарный поиск     | Merge Sort, Quick Sort, Binary Search                            |
| **Recursion & Backtracking** | Генерация вариантов, деревья   | Permutations, N-Queens, DFS                                      |
| **Greedy Algorithms**        | Оптимизация, задачи на ресурсы | Jump Game, Gas Station                                           |
| **Dynamic Programming**      | Оптимизация, мемоизация        | Climbing Stairs, House Robber, Longest Common Subsequence        |
| **Graph Traversal**          | Компоненты, связи              | BFS, DFS, Shortest Path, Topological Sort                        |

## 📦 Helpful Patterns / Preprocessing Techniques

| 🧰 **Техника**                 | 🧠 **Описание**                                             | 💼 **Примеры задач**                               |
| ------------------------------ | ----------------------------------------------------------- | -------------------------------------------------- |
| **Prefix Sum**                 | Препроцессинг массива для быстрого подсчёта суммы диапазона | Range Sum Query, Subarray Sum Equals K             |
| **Difference Array**           | Быстрое обновление диапазонов                               | Range Addition, Flight Bookings                    |
| **Frequency Table / Hash Map** | Подсчёт частот символов, чисел и fast lookup                | Anagram, Top K Elements, Majority Element          |
| **Monotonic Stack / Queue**    | Поиск следующего/предыдущего большего/меньшего элемента     | Daily Temperatures, Largest Rectangle in Histogram |
