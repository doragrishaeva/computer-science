# 🧭 Two-Pointer Pattern

The **two-pointer pattern** is a common array and string traversal technique that uses two indices (pointers) to efficiently solve problems that would otherwise require nested loops.

---

## ✅ When to Use

Use the two-pointer technique when:

- You're dealing with a **sorted array or string**
- You need to **search for a pair** or subset of elements
- You want to **compare elements** from both ends of a collection
- You're trying to **remove duplicates in-place**
- You need to partition or manipulate arrays with **minimal extra space**
